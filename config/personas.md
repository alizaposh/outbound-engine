# Config: Personas

Per-persona guidance for message generation. This is where stakeholder feedback like
"for this persona, lead with the operational problem, not the revenue opportunity"
gets encoded as a reusable rule.

## How to use
When generating, match the prospect's title/role to a persona below and apply its
angle. If no persona matches, use the default and flag it.
